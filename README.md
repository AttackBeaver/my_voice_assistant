# Голосовой ассистент "Руна"

Офлайн голосовой помощник для управления компьютером, открытия приложений, управления окнами, поиска в интернете, напоминаний и других задач. Проект полностью работает локально и не требует подключения к интернету (кроме погоды). Максимально гибко настраивается и просто масштабируется.

## Возможности

- Полностью офлайн распознавание речи (Vosk)
- Синтез речи (pyttsx3)
- Активация голосом (имя "Руна")
- Открытие браузера и переход на сайты
- Управление окнами: свернуть все, развернуть все, закрыть все, закрыть активное окно, показать рабочий стол
- Открытие папок
- Получение погоды (wttr.in, опционально)
- Напоминания с таймером (голосовое напоминание через заданное время)
- Приветствие с временем, днём недели и датой
- Выключение и перезагрузка компьютера с голосовым подтверждением

## Требования

- Python 3.8 или выше
- Windows (поддержка WinAPI для управления окнами)
- Микрофон и колонки (или наушники)

## Установка

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

3. Активируйте его:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`
4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Скачайте модель распознавания Vosk для русского языка:
   - Перейдите на [сайт Vosk](https://alphacephei.com/vosk/models)
   - Скачайте модель `vosk-model-small-ru-0.22` (45 МБ)
   - Распакуйте архив в папку `model/` в корне проекта.
6. Убедитесь, что путь к модели правильный (по умолчанию `model/vosk-model-small-ru-0.22`).

## Запуск

```bash
python src/assistant.py
```

При первом запуске ассистент произнесёт приветствие. Далее скажите "руна" для активации, после чего произносите команду.

## Команды

Голосовые команды (после активации словом "руна"):

| Команда | Действие |
| --------- | ---------- |
| открой браузер, открой яндекс браузер | Открывает Яндекс.Браузер (если установлен) |
| работаем, рабочий режим, воркать | Открывает заданные папки и два окна браузера на двух мониторах |
| закрой все, закрыть все | Закрывает все открытые окна (5 раз Alt+F4) |
| закрой активное окно | Закрывает только активное окно (Alt+F4) |
| сверни все, свернуть все, шухер, шмон | Сворачивает все окна (Win+M) |
| разверни все, развернуть все | Разворачивает все свёрнутые окна (Win+Shift+M) |
| покажи рабочий стол, рабочий стол | Показывает рабочий стол (Win+D) |
| как дела, как твои дела | Случайный ответ о состоянии |
| танцуем, танцы | Открывает YouTube-видео (Rick Astley) |
| что умеешь, расскажи о себе, помощь | Справка |
| поздоровайся, скажи привет | Повторяет приветствие (время, дата, погода) |
| напомни через X минут/секунд/часов [текст] | Устанавливает напоминание с таймером |
| погода | Озвучивает текущую погоду |
| найди в интернете [запрос] | Открывает Яндекс.Поиск с запросом |
| найди в интернете на втором мониторе [запрос] | Открывает поиск на втором (левом) мониторе |
| выключи компьютер, выключить | Выключает компьютер (с подтверждением) |
| перезагрузи компьютер, перезагрузка | Перезагружает компьютер (с подтверждением) |
| стоп, выход | Завершает работу ассистента |

## Конфигурация

Основные параметры находятся в начале файла `src/assistant.py`:

- `MODEL_PATH` — путь к папке с моделью распознавания (по умолчанию "model")
- `WAKE_WORD` — слово активации (по умолчанию "Руна")
- `COOLDOWN_SECONDS` — время кулдауна в секундах после выполнения команды (2 сек)
- `YANDEX_BROWSER_PATH` — путь к исполняемому файлу Яндекс.Браузера (если None, ищется автоматически)
- `FOLDERS_TO_OPEN` — список путей к папкам, которые открываются по команде "работаем"

## Примечания

- Проект полностью офлайн, кроме получения погоды (запрос к wttr.in). При отсутствии интернета погода пропускается без ошибок.
- Для работы с двумя мониторами используется библиотека screeninfo. Если монитор один, все окна открываются на основном.
- Управление окнами осуществляется через WinAPI (ctypes) и не требует прав администратора, но выключение/перезагрузка могут требовать прав.
- Все голосовые команды произносятся на русском языке.
