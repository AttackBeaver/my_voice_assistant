# Голосовой ассистент "Руна"

Офлайн голосовой помощник для управления компьютером, открытия приложений, управления окнами, поиска в интернете, напоминаний и других задач.  
Проект полностью работает локально (интернет требуется только для получения погоды).  
Ассистент запускается скрыто, имеет иконку в системном трее и автоматически добавляется в автозагрузку Windows.

## Возможности

- Полностью офлайн распознавание речи (Vosk)
- Естественный синтез речи через встроенный движок Windows SAPI (высокое качество, регулируемая скорость и громкость)
- Голосовая активация (имя "Руна")
- Мгновенное прерывание текущей речи при активации
- Управление окнами:
  - Свернуть все, развернуть все, закрыть все, закрыть активное окно, показать рабочий стол
  - Управление через WinAPI (не зависит от фокуса мыши)
- Открытие заданных папок и браузера (Яндекс.Браузер) с размещением окон на двух мониторах
- Поиск в интернете (Яндекс) на основном или втором мониторе
- Получение погоды (wttr.in) с переводом на русский
- Напоминания с голосовым таймером (поддерживаются числа и словесные числительные)
- Приветствие с временем, днём недели, датой и погодой
- Реакция на похвалу и вопрос "как дела"
- Команда "танцуем" для открытия забавного видео (Rick Astley)
- Выключение, перезагрузка и спящий режим с голосовым подтверждением
- Расширенные синонимы для всех команд (учтены варианты с буквой Ё)
- Иконка в системном трее с возможностью закрыть ассистент
- Автоматическая установка в автозагрузку Windows (при первом запуске)
- Скрытый запуск (без консольного окна) через `pythonw.exe`

## Требования

- Python 3.8 или выше
- Windows (используются WinAPI и SAPI, поэтому только Windows)
- Микрофон и колонки (или наушники)

## Установка

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

3. Активируйте его:
   Windows: `venv\Scripts\activate`
4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Скачайте модель распознавания Vosk для русского языка:
   - Перейдите на [сайт Vosk](https://alphacephei.com/vosk/models)
   - Скачайте модель `vosk-model-small-ru-0.22` (45 МБ)
   - Распакуйте архив в папку `model/` в корне проекта.
6. Убедитесь, что путь к модели правильный (по умолчанию `model/vosk-model-small-ru-0.22`).  
   (Путь вычисляется автоматически относительно скрипта, поэтому не требуется дополнительных настроек.)

## Запуск

### Обычный запуск (с консолью, для отладки)

```bash
python src/assistant.py
```

### Скрытый запуск (без окна, для повседневного использования)

Используйте ярлык, который создаётся автоматически в папке автозагрузки, или запустите через `pythonw.exe`:

```bash
pythonw src/assistant.py
```

При первом запуске скрипт автоматически создаст ярлык в папке `Startup`, поэтому после перезагрузки ассистент будет запускаться сам.  
Иконка в системном трее позволяет завершить работу ассистента.

## Команды

После активации словом **«Руна»** произносите одну из команд.  
Многие команды имеют несколько синонимов – выберите удобный для вас.

| Что сказать | Действие |
| ------------- | ---------- |
| **работаем / работа / рабочий режим / воркать / на работу / начинаем работу** | Открывает заданные папки и два окна Яндекс.Браузера на двух мониторах |
| **закрой все / закрыть все** | Закрывает все окна (Alt+F4 несколько раз) |
| **закрой активное окно** | Закрывает только активное окно |
| **сверни все / свернуть все / шухер / шмон / спрятать все окна** | Сворачивает все окна (Win+M) |
| **разверни все / развернуть все / восстановить окна** | Разворачивает все свёрнутые окна (Win+Shift+M) |
| **покажи рабочий стол / рабочий стол / очистить экран** | Показывает рабочий стол (Win+D) |
| **как дела / как твои дела / как жизнь / как настроение / как сам** | Случайный ответ о состоянии |
| **танцуем / танцы / потанцуем / вруби танцы** | Открывает YouTube-видео (Rick Astley) |
| **что умеешь / расскажи о себе / твои возможности / помощь / справка** | Справка о всех командах |
| **поздоровайся / скажи привет** | Повторяет приветствие (время, дата, погода) |
| **напомни через X минут/секунд/часов [текст]** | Устанавливает напоминание (поддерживаются числа и слова: «десять», «пять» и т.д.) |
| **погода / какая погода / что на улице / температура** | Озвучивает текущую погоду |
| **найди в интернете [запрос]** | Открывает Яндекс.Поиск с запросом |
| **найди в интернете на втором мониторе [запрос]** | Открывает поиск на втором (левом) мониторе |
| **выключи компьютер / выключить** | Выключает компьютер (с голосовым подтверждением) |
| **перезагрузи компьютер / перезагрузка** | Перезагружает компьютер (с подтверждением) |
| **спящий режим / усыпи / спать / перевести в сон** | Переводит компьютер в спящий режим (с подтверждением) |
| **стоп / выход** | Завершает работу ассистента |

### Управление через системный трей

- Иконка в трее (чёрный квадрат с белым кружком) показывает, что ассистент работает.
- Правый клик по иконке → меню, где можно выйти из приложения.

## Конфигурация

Основные параметры находятся в начале файла `src/assistant.py`:

- `MODEL_PATH` — путь к папке с моделью распознавания (вычисляется автоматически, обычно `../model`)
- `WAKE_WORD` — слово активации (по умолчанию "руна")
- `COOLDOWN_SECONDS` — время кулдауна в секундах после выполнения команды (2 сек)
- `YANDEX_BROWSER_PATH` — путь к исполняемому файлу Яндекс.Браузера (если None, ищется автоматически)
- `FOLDERS_TO_OPEN` — список путей к папкам, которые открываются по команде "работаем"
- Скорость и громкость речи регулируются в `__init__` через `self.speaker.Rate` и `self.speaker.Volume` (диапазон -10..10 и 0..100 соответственно).

## Зависимости

Основные библиотеки (указываются в `requirements.txt`):

- `vosk` – распознавание речи
- `sounddevice` – захват аудио
- `numpy` – обработка аудиоданных
- `pyautogui`, `screeninfo` – управление окнами и мониторами
- `requests` – получение погоды
- `pystray`, `Pillow` – иконка в системном трее
- `pywin32` – синтез речи через SAPI и работа с WinAPI
- `pyttsx3` – оставлен как резерв (не используется, но может быть удалён)

## Примечания

- Проект полностью офлайн, кроме погоды (запрос к wttr.in). При отсутствии интернета погода пропускается без ошибок.
- Для работы с двумя мониторами используется библиотека screeninfo. Если монитор один, все окна открываются на основном.
- Управление окнами выполняется через WinAPI (ctypes) – не требует прав администратора, но выключение/перезагрузка/сон могут требовать прав.
- Все голосовые команды произносятся на русском языке.
- Ассистент автоматически добавляется в автозагрузку при первом запуске через `pythonw.exe`. Ярлык создаётся в папке `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`.
- Если вы хотите обновить ассистент, просто замените файл `assistant.py` и перезапустите его (через иконку в трее или через ярлык). Ярлык в автозагрузке остаётся тем же.

## Устранение неполадок

- Если ассистент не запускается через ярлык, проверьте, что в свойствах ярлыка указана рабочая папка.
- Если нет звука, убедитесь, что в Windows выбран рабочий аудиовыход и громкость не выключена.
- Если не распознаются команды, проверьте микрофон и уровень шума в помещении.
- Логи ошибок можно увидеть, запустив скрипт через `python` (не `pythonw`) – в консоли будут выводиться сообщения.
